# Hasita Mandaleeka, Personal Portfolio

A space-themed personal portfolio with a hidden interactive constellation, showing my love for deep thinking and space. Built for the AWS Student Builder Challenge.

**Live site:** https://main.dh5b54u1opv9k.amplifyapp.com/ 

<img width="750" alt="Portfolio home page" src="https://github.com/user-attachments/assets/f84345c0-b45c-4d0e-a0cd-8efb1c929ff5" />

## Features
- Sections: Mission Briefing (home), The Person Behind the Code (about), Technical Systems (skills), Mission Archives (projects), Open Communications (contact)
- Beyond the Code: find 7 hidden stars (and crack open drifting rocks) to trace a constellation and learn about me along the way

## Built With
Built with an AI coding agent (Claude Code) connected to AWS, as encouraged by the challenge

## AWS Usage
- AWS Amplify Hosting

## What I Learned
- Deploying on AWS is more approachable than I expected. Connecting GitHub to Amplify gave me automatic redeploys on every push. 
- Hidden features need gentle clues like a twinkling star, a hint line and a progress bar to let visitors discover the constellation.
- I paired with an AI coding agent (Claude Code) connected to AWS. It sped up building and deploying, while I made the design, content and storytelling decisions and reviewed what it produced.

## Run Locally
Clone the repo and open index.html in a browser.
